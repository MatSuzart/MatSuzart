# Hi there, I'm Matheus Suzart

I currently work mainly with **Python, TypeScript and SQL**, building automation tools, APIs and data workflows.
I enjoy working close to the system layer: **Linux, backend architecture and data pipelines**.
Recently I have been studying **algorithms and robotics (ROS 2)** to strengthen my engineering foundations, while expanding the map both in code and in life.

## How it all started

It all started when I saw my **first script in the RPG Tibia**.
That was my first contact with **programming logic and automation**, and I immediately fell in love with it.

Soon I started writing my own scripts.
So if you ever stumbled upon a bot during a hunt back in the day... I'm sorry about that.

After that, I built my **first real project**: a website for a friend's Tibia server.
That little project ended up opening the door to **web development, backend systems and automation**, which is the path I continue exploring today.
